My entry for the make.fun bounty [The Printer Finally Answers](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907): the machine on the corner of the office finally says what it has been thinking through every paper jam, every flashing error code, and every mysterious clunk halfway through a print job.

`main.py` saves that one line to `/output/entry.txt`:

> I didn't jam. I ate your document. It tasted like urgency and poor planning.

## Run it

```sh
python3 main.py
```

By default the file lands in `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to another folder and that is where it will go.
